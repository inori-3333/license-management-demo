# 原界面自动演示

## 用户要求与实现

- 保留原有页面和布局，在当前应用中演示；不创建 iframe、新页面或整页演示弹窗。
- 可见演示鼠标连续移动、停顿、点击；点击有圆环反馈，文本逐字输入。
- 按用户最新反馈合并为 16 段业务流程；同类报表与维度只展示代表用法。页面就位后稳定 1 秒，再逐字变色讲解（每字 180 毫秒、至少 4.2 秒），全句变色后保留 1.2 秒。卡片显示下一段名称。操作提示限两行、40px，只在实际操作时显示；阅读、等待和暂停时文字、标记与背景均留空。
- 字幕讲解期间自动操作停止，页面、目标和卡片保持稳定；已可见控件不反复居中，同一业务区域的卡片优先保留原位置。
- 讲解卡片随目标移动，并根据目标、选项和视口空间避让。业务弹窗仍采用原有 Modal；讲解和指针放在当前弹窗内的手动 Popover 顶层。
- 全部移动、输入和阅读共享可暂停时钟；退出取消剩余动作。原有数据始终保留，演示仅修改内存副本，结束后恢复原页面与密度。
- 下拉选项以只读预览显示选择过程，随后更新原控件。文件仍走真实导入解析与导出生成逻辑；系统文件选择、打印窗口不自动弹出以免阻断演示。

## 验证方法

`npm run test:demo` 的完整业务回归使用浏览器时钟和测试注入的播放速率加速，以检查全部 16 段业务流程（每段讲解不超过 40 字）、11 个真实文件、整改拦截/销项/重开和原数据恢复。该用例不用于证明实际观看速度。

独立的标准速度用例检查：鼠标中间位置连续变化；暂停后位置冻结且操作提示留空；展开选项可见；卡片避开目标；页面就位后才开始读字；字幕出现部分变色并按顺序推进；暂停冻结字幕；整个讲解期间 URL、滚动位置、目标和卡片边界不变；全句变色后仍保留停留时间；随后才自动进入下一段。另检查逐字输入中途暂停、业务弹窗中重播、退出及原数据恢复。

61 项单元/业务测试通过，包括 56 项原有计算测试与 5 项逐字讲解时间、颜色进度和卡片定位测试。原始岗位数据核对、构建、静态子路径资源、设计 tokens/对比度和格式检查一并运行。
