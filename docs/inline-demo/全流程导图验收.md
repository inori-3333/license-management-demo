# 自动演示后的全流程导图

日期：2026-09-21。验证范围为本地开发页面与生产构建；本次未发布线上。

## 呈现与交互

- 16 段实际业务操作及最后一段讲解完成后，原应用主内容区显示导图，演示指针与聚焦框退出。
- 六个颜色区分的阶段：数据归集 → 人岗证台账 → 规则匹配 → 监测预警 → 整改复核 → 分析应用；整改回连台账表示补证后重新校验。
- 原 16 个环节全部保留，编号与讲解来自现有演示脚本；设置、备份和演示重置作为支撑能力展示。
- 点击或键盘选择节点可查看对应讲解。桌面在图下展示，窄屏在所选节点内展开；不会自动切换或滚动。
- 流动连线可暂停／继续，Escape 或切到后台暂停；动态响应系统减少动态效果偏好。
- 11 个演示文件仍可下载；结束或重播后退出均恢复原 URL、数据和密度，焦点回到自动演示入口。
- 平板顶栏允许操作区换行，修正加入演示按钮后在 684px 出现的横向溢出。
