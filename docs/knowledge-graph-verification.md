# 知识图谱验收记录

2026-09-22。根据用户补充，默认页面已从按实体类别分区改成全量三维人员点云，去掉中心人数圆盘、簇圆形边界及画布分页。旧实体追溯功能保留在 `?view=entities`。

## 当前数据与业务口径

- 当前种子台账 1364 人全部进入同一个三维空间，每人一个点；无证或无当前关系人员保留为灰色点。
- 默认有效证书口径：37 个簇，1349 名持证人员。同一人的多个持证关系共同影响空间位置，不复制人员点。
- 证书按当前状态和既有别名归集，支持有效 / 全部记录。按岗位、公司、专业聚类时使用当前有效任职。
- 相同关系组合形成局部点云；点击多证人员默认选择其成员较少的证书簇，可从详情切换其他证书。聚焦使用完整成员范围，不抽样。

## 浏览器验证

本地 Vite 页面，Codex 浏览器。已检查桌面和手机视口。

- 职业技能等级证书（初级工）1175 人全部属于该簇；名单从 1–30 翻到 31–60，搜索 DEMO0733 得到陈华6，并展示两个关联证书簇。
- 高压电工作业证有效持有人 12 人，全部记录口径 14 人，保留已过期状态。
- 画布实际点击取证示例·起重机指挥作业证的人员点，选中该人员并聚焦其证书簇。相机 yaw 从 1.948 开始变化，缩放从 100% 拉近，整个过程仍保留 1364 个三维数据点。
- 通过目录聚焦高压电工作业证 12 人，成员计数与完整簇一致；镜头有旋转、平移与缩放。
- 全景投影计数实测为 1364；暂停后可手动旋转、缩放。名单分页和搜索不删除三维数据。
- 系统 reduced-motion 由媒体查询禁用漂浮和自动环绕，并即时定位。本轮没有改变操作系统动态效果偏好。
