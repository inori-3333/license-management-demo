# 前端演示体验检查 · 2026-09-21

基于当前工作区正在运行的本地版本（包含未提交的自动演示功能），使用 Codex 内置浏览器检查。桌面截图为 1280×720，另检查 684×837 和 390×844。所有截图均在本轮捕获并逐张查看，文件保留浏览器返回的原始图像。

结论：现有中文工作台风格、待办下钻、来源追溯和移动台账卡片可以保留。最值得优化的是讲解卡片遮挡、现场演示导航，以及整改主操作的可见性。此次只新增审查材料，没有修改应用源代码。

## 优先级与可验收建议

P1 表示优先影响演示连贯性；P2 表示影响理解或操作效率；P3 表示进一步提升首次体验。这里的优先级针对前端演示体验，不代表业务计算错误。

### 1. P1 · 演示讲解卡片会遮挡业务结果

观察：截图 11、13、15、16：卡片避开正在操作的选择器或搜索框，但覆盖待办、筛选器和人员结果；390px 下收起设置后仍占据约 300px 高度。

建议：桌面给讲解与关键结果预留独立区域，或增加固定边栏／收起控制；窄屏用可收起的底部讲解区并为内容预留空间。把当前结果区域也纳入避让，保留已有逐字变色及阅读期间稳定布局。

验收：同屏能看到当前操作、产生的结果和播放控制；展开设置后仍可收起；阅读期间不移动页面。

### 2. P1 · 自动演示缺少现场讲解所需的导航

观察：截图 11—16：只有暂停／继续、下一条、倍速和从头重新演示，没有章节目录、上一段或本段重播；执行步骤时下一条置灰且未解释原因。第 2 段先改分页、翻页和切密度，再开始查询人员。

建议：保留 16 段完整流程，提供章节目录、上一段、本段重播和精简演示入口；操作期把按钮标成“本段操作完成后可继续”或展示简短阶段状态。需要前置数据的章节用独立场景快照恢复，不能直接跳过依赖操作。

验收：观众要求重看或只看整改时能直接定位；短版围绕“发现缺证 → 补证 → 复核 → 指标变化”，完整功能演示仍可选择。

### 3. P1 · 整改弹窗的主操作落在首屏之外

观察：截图 03：1280×720 下，弹窗展示了对象信息、问题、五段流程和输入框，但取消、分派整改按钮需要继续滚动。

建议：缩短对象摘要，当前阶段只突出本阶段必填项；把主操作固定在弹窗底部，内容独立滚动；其他阶段信息保持可展开。

验收：720px 高度及窄屏下，主要操作始终可见，且不遮挡输入框；键盘焦点与错误提示可达。

### 4. P2 · 统计数量缺少明确的范围和单位

观察：截图 01、02：11 项合规问题下钻后，选中的分类为 11，而页签仍写待处理 855；首页待补充为 46 人，问题页为 47，后者没有标明“项”。代码显示页签取全部问题总数，表格取筛选结果，不能据此认定计算错误。

建议：显示“当前筛选 11 项／全部待处理 855 项”，给分类数量补单位；把“涉及人数”和“问题项数”分开。首页把 79.6% 的 43/54 分母与 1,363 人总范围的关系写得更直白，并保留统计日期口径。

验收：用户无需跳到页尾或听口头解释，就能理解筛选数量、总数量与各指标分母。

### 5. P2 · 关键结论出现得偏晚，跨页任务衔接可加强

观察：截图 04：人员首屏只提示不合规及 3/4 项，缺少的具体证书在任职大卡片之后；由整改进入后顶部返回入口指向人员台账，另有查看相关问题，但没有回到原整改事项的直接入口。截图 05：报表筛选区占约 284px，首屏仅完整看到第一行结果。

建议：人员页在顶部直接显示“缺少起重机司机作业证 → 补录”，任职概要压缩，详细来源展开；从整改进入时保留原事项返回入口。报表保留常用条件，把高级条件折叠，结果前给出一段有分母和范围的简短摘要。

验收：在常见笔记本首屏内能回答“缺什么、为什么、下一步做什么”；处理后能回到原整改上下文。

### 6. P2 · 人才画像的手机端结果比较困难

观察：截图 09、10：390px 下先经过较长条件区才到结果，结果仍为横向表格；当前任职频繁换行，资格匹配和缺口在屏幕右侧不可同时看见。

建议：复用人员台账已有的手机摘要卡片：姓名、当前任职、匹配结论、缺口、选择操作同卡呈现；证书标签与来源按需展开，条件区支持收起。

验收：无需横向滚动即可看到一个人的身份、匹配结论和缺口，并保留选择、分页与导出范围语义。

### 7. P3 · 补足首次观看者的演示入口和阅读提示

观察：截图 01、06、07：统计日期为固定演示日期，导入入口要求自备文件，规则列表默认展示较多配置语句；12px 辅助文字用于多个关键说明。

建议：在演示入口说明本次展示范围、临时副本和所用统计日期；导入页提供“使用示例文件预览”，先预览后确认；规则增加一句自然语言摘要。可提供面向投屏的字号选项，并将关键结论提升到正文层级。

验收：第一次打开即可开展一条完整讲解；演示标识清楚；未知值、原始来源和判定依据仍完整可查。

## 可访问性与证据边界

已确认：页面有中文可访问名称和语义化按钮／链接；状态除了颜色还有文字；台账空结果可以恢复；键盘激活清空按钮后焦点返回搜索框；抽查浏览器未记录 error/warn。项目颜色 token 对比度检查通过。

风险：讲解面板可遮住业务内容，窄屏画像需要双向滚动，关键说明字号较小可能增加投屏阅读负担。小字号属于可读性建议，未以此判定 WCAG 违规。静态对比度脚本不代表所有实际叠加状态已满足可访问性要求。

本轮自动演示仅实际观看第 1 段及第 2 段的部分操作，并验证暂停、设置、退出和首页状态恢复，没有完整播放 16 段；未执行修改证书后的完整整改销项、导入文件、实际打印、全量导出内容核对，也未做真机触屏、屏幕阅读器、200% 缩放、完整减少动态效果矩阵或线上 Pages 对比。不能把当前审查当作这些流程的全面验收。
